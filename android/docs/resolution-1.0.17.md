# 1.0.17 分辨率修复整合报告

日期：2026-10-17。官方基线：`801db8bcbd970b573dd2e89cb9f2b0aab16789d8`（1.0.17）。
移植来源：1.0.15整合版代码提交 `54c0004`，最初修复来自1.0.12第四版。
测试版本：`1.0.17-resolution-test.7`；版本码10017；非官方Debug构建。

## 四项本地修复

1. 登录连接提示贴边映射；标题、点击提示和连接提示有限的位置/尺寸搜索；低分辨率模板采样。连接状态等待，保留总超时。
2. 独立测试包控制台8766，官方构建8765；页面、下载和服务器使用统一地址配置；等待状态也包含版本、包名及端口。
3. 角色加入标题及关闭按钮均强匹配、与背景地图竞争时优先识别弹窗，避免因分差不足判为未知页。
4. 两种已有WIN下一步按钮候选启用局部匹配，使用最佳矩形点击，保留0.80门槛。

## 安装与试跑

APK包名 `com.landosol.toolbox.resolutiontest`，与此前测试版相同，使用同一本地签名，可直接覆盖升级保留设置；官方包可并存。测试版控制台端口8766。

1.0.15整合版曾由用户反馈连续5轮美食殿堂顺利完成；这一历史结果不代表1.0.17已完成实机验收。当前版本等待用户安装后再跑一轮。建议特别留意战斗后进入事件自选、商店选择印记以及会话恢复后的选择/邀请确认，并验证原有登录、角色加入及WIN下一步。

游戏保持前台、允许横屏旋转，并关闭“播放角色加入动画”。若异常，保存测试版debug包、轮次和停住画面；新版日志中的应用身份与运行指标有助于核对。

已有截图缩放验证不代表每种设备、宽高比、公会和渠道服均已通过。历史公会选择卡住仍未取得故障现场确认，不据版本升级宣称消除所有卡点。

## 构建与分享

从android目录执行（JDK17及对应Android SDK）：

```sh
./gradlew -PresolutionTest=true :app:lintDebug :app:testDebugUnitTest :app:assembleDebug
```

分享包包含APK、源码补丁、报告、测试统计、匹配指标和签名校验。原始debug包、账号凭据、本地工具链及签名私钥未提交。
