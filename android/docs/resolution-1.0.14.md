# 1.0.14 分辨率修复整合报告

日期：2026-09-25。官方基线：`3f088c268730b7434e7f519585589ad0fbc734a3`（1.0.14）。
移植来源：`4bc4d8785137ff3dbadbc4880399fc48417f2418`（1.0.12第四版）。
整合版：`1.0.14-resolution-test.5`，非官方Debug构建。

## 四项修复

1. **登录分辨率适配。** 连接提示采用贴边映射，登录标题/提示增加有限的位置与尺寸搜索，低分辨率文字采用对应尺寸采样。识别连接中后等待，保留总超时。
2. **控制台隔离。** 测试包 `com.landosol.toolbox.resolutiontest` 使用8766；原版构建使用8765。服务器、打开控制台、下载日志共用地址配置，等待状态也显示版本身份。
3. **角色加入弹窗。** 标题及关闭按钮均强匹配、竞争对象为背景地图时优先识别弹窗，避免两者分数接近而判UNKNOWN。
4. **WIN下一步。** 两种已有按钮位置增加小范围位置/尺寸搜索，点击最佳匹配矩形，保留0.80阈值。

## 保留的官方功能

- 1.0.13的自动执行主流程、任务级公会选择、合格且尚未推进的开局首轮复用一次、稳定横屏捕获和模板匹配预计算优化。
- 1.0.14的多渠道服、紧凑横屏界面、返回标题按钮连续多帧确认、无障碍手势回调及时释放任务引用。
- 1.0.14的标题页点击间隔5秒；本地回归测试相应更新时间序列，没有改回旧间隔。

版本、匹配器、主页及版本测试的重叠改动均按“保留上游实现，再叠加四项修复”处理。测试版仍使用10014版本码，与第四版同一测试包名及本地签名，可覆盖升级保留数据；不替换官方包。

## 限制和后续验收

1.0.12第四版已有用户“一轮测试通过”反馈；这不是1.0.14整合版的实机验收。真实截图缩放测试不等于每个设备/宽高比都通过。

本次未合入额外的Boss长战斗保护修改。官方1.0.14发布说明明确指出，部分挑战按钮开战后的长战斗可能约30秒超时，其修复未进入该版本。公会选择卡住尚未捕获现场确认；4399协议弹窗与其他渠道服限制仍以官方说明为准。

建议先在原有MuMu、原有分辨率和B服账号上验证登录、角色加入、WIN下一步及完整一局，再测连续多局。游戏保持前台，允许横屏旋转，并关闭“播放角色加入动画”。

## 构建

从android目录运行（JDK17及对应Android SDK）：

```sh
./gradlew -PresolutionTest=true :app:testDebugUnitTest :app:assembleDebug
```

游戏账号、凭据、原始debug包和签名私钥未纳入分享包或Git提交。回归截图来源和脱敏说明见测试素材目录README。
