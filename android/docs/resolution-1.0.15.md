# 1.0.15 分辨率修复整合报告

日期：2026-10-04。基线：官方1.0.15发布提交 `b8d8af912269cfea9ad65fd4e284d0d64da8e118`。
修复来源：1.0.14整合版的代码提交 `98214d5`；历史实测来源为1.0.12第四版。
新测试版：`1.0.15-resolution-test.6`，非官方Debug构建，版本码10015。

## 保留的四项修复

1. 登录连接提示贴边定位、标题与提示的有限位置/尺寸搜索、低分辨率模板采样；连接中等待，保留原总超时。
2. 测试包控制台8766与官方包8765隔离；页面、下载和服务器共用地址配置，初始状态显示应用身份。
3. 角色加入标题及关闭按钮均强匹配时，优先识别覆盖地图的弹窗，避免分数接近被判为未知页。
4. 两种已有WIN下一步按钮位置进行小范围局部匹配，点击最佳匹配矩形，保留0.80门槛。

## 保留的1.0.15变化

- 帆稀（龙妈）升星头像模板修正及对应成员识别回归。
- 单独刷开局按界面当前选择的公会运行。
- 初始角色不在当前屏时继续查找，不因未测得/全高滚动条或尚未识别卡片就直接判到底。
- 咲恋救济院默认第三名初始角色改为圣诞咲恋；已有自定义方案仍优先。
- 无障碍权限引导及自动执行说明更新。
- 游戏已在前台时直接接管，地图短暂出现后才弹出的初始角色选择页仍按开局处理。

1.0.14及此前的渠道服支持、紧凑界面、返回标题连续确认、手势回调引用释放、开局首轮复用和匹配预计算优化均保留。

版本构建与版本测试冲突已解决为1.0.15/10015；其他移植改动经源码差异复核，没有覆盖上游初始角色查找及冷启动接管实现。没有加入四项之外的流程行为修改。

## 复核命令

从android目录运行（JDK17及对应Android SDK）：

```sh
./gradlew -PresolutionTest=true :app:lintDebug :app:testDebugUnitTest :app:assembleDebug
```
